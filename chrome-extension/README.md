# 校园网自动登录 · Chrome / Edge 扩展

自动登录校园网门户 **http://172.30.100.2/**（Dr.COM / 哆点 ePortal），掉线自动重连。
原生兼容 **Google Chrome** 与 **Microsoft Edge**。

> ### ⚠️ 改完代码没生效？先看这里
>
> 浏览器只在**加载扩展的那一刻**读取代码，之后一直用内存里的旧副本。
> 改了磁盘文件不点刷新是不会生效的 —— 这是浏览器的正常行为，不是插件的问题。
>
> **方法 A（推荐）**
> 1. 双击项目根目录的 **`reload_extension.bat`**（会自动打开扩展管理页；Edge 用户可执行 `reload_extension.bat edge`）
> 2. 在「Campus AutoLogin」卡片上点 **🔄 刷新**
> 3. **关掉已打开的设置页，重新打开**（旧标签页里仍是旧代码）
>
> **方法 B（最省事）**
> **完全退出浏览器再重新打开**。重启后所有扩展都会重新从磁盘加载。
>
> 确认成功的标志：设置页左上角品牌区出现版本号（与 `chrome-extension/manifest.json` 的 `version` 一致）。
> 该判据依赖**每次发版都递增 `version`**；若两次改动间版本未变，刷新前后显示相同属正常，
> 请改用「关掉旧设置页标签再重开 + 观察设置项文案/布局变化」来确认。

## 安装（30 秒）

### Google Chrome 用户
1. 地址栏输入 `chrome://extensions/` 回车；
2. 打开右上角 **「开发者模式」** 开关；
3. 点击左上角 **「加载已解压的扩展程序」**；
4. 选择解压后的扩展文件夹（如使用源码仓库，选择仓库下的 **`chrome-extension`** 目录）；
5. 点击工具栏的插件图标 → **控制中心**，填入账号密码 → **保存并连接**。

### Microsoft Edge 用户
1. 地址栏输入 `edge://extensions/` 回车；
2. 打开左侧（或左下角）**「开发人员模式」** 开关；
3. 点击顶部的 **「加载解压缩的扩展」** 按钮；
4. 选择解压后的扩展文件夹（如使用源码仓库，选择仓库下的 **`chrome-extension`** 目录）；
5. 点击工具栏的插件图标 → **控制中心**，填入账号密码 → **保存并连接**。

> 💡 如果工具栏看不到图标，点击地址栏右侧的「拼图」图标，把「Campus AutoLogin」固定住即可。

## 重连有多快？

三层保障，从快到慢：

| 层级 | 触发时机 | 延迟 |
| --- | --- | --- |
| ① 断网跳转瞬间 | 导航失败 / 被跳到门户 | **≈ 0 秒** |
| ② 掉线后高频轮询 | 确认掉线（门户可达但未认证），每 1 秒重试 | **≤ 1 秒** |
| ③ 在线时低频轮询 | 常规守护，默认 10 秒 | 兜底 |

> **区分「掉线」与「不在校园网内」**：门户可达但未认证才是真·掉线，按「掉线间隔」（默认 1 秒）
> 快速抢修。若门户**根本连不上**（多半是人不在校园网内），先按掉线间隔快速重试约 10 次，
> 之后指数退避：2 → 4 → 8 → 16 → 32 → 60 秒封顶。一旦重新能连上门户，立刻恢复常规节奏。
> 这样既保证校园网瞬断能在十几秒内恢复，又不会在宿舍外把浏览器变成每秒一次的请求机器。

**关于 1 秒间隔**：Chrome 官方文档写 `chrome.alarms` 最快 30 秒，但那条限制
**只对「已打包 / 从商店安装」的扩展生效**；开发者模式加载的未打包扩展不受限制。
本插件在 Chrome 154 上实测：

```
闹钟 campus-auto-login  period = 0.0167 分 = 1.0 秒   ← Chrome 原样接受，未被夹紧到 30 秒
16 秒内触发 16 次                                     ← 精确 1 秒/次
```

> 如果你以后把这个插件打包发布到应用商店（Chrome / Edge），间隔会被浏览器自动夹到 30 秒。
> 本地开发者模式加载使用不受影响。
>
> 另外「1 秒」是**尽力而为**的目标而非硬保证：Chrome 只承诺 alarms 不会快于 1 秒、
> 且触发可被任意延迟；瞬时触发还有 15 秒节流窗口（后台忙被跳过时缩短为 1 秒重试），
> 单轮流程包含 SW 冷启动、运行态恢复
> 与最多 3 次 8 秒超时的门户请求。上面的实测数据是特定版本下的结果，不代表所有环境。

## 设置项

| 选项 | 说明 |
| --- | --- |
| 账号 | 校园网账号（手机号 / 学号），**需自己填写**（源码内不含任何凭据） |
| 密码 | 校园网密码，可点「显示」查看，**需自己填写** |
| 运营商 | `校园用户`（默认，无后缀）/ `校园电信`（`@dx`）/ `校园联通`（`@lt`）/ `校园其他`（无后缀）；仅用于选择门户 `R3` 参数，账号框填纯学号/手机号即可 |
| **在线时的检查间隔** | 默认 **10 秒**（可选 1 秒 / 5 秒 / 10 秒 / 30 秒 / 1~30 分钟） |
| **自适应加速** | **默认开** —— 确认掉线后自动切到「掉线间隔」，重连成功再切回 |
| **掉线后的检查间隔** | 默认 **1 秒**（可选 1 / 5 / 10 / 30 秒 / 1 分钟） |
| **断网跳转时立即登录** | **默认开**，最快的重连方式 |
| 浏览器启动时自动登录 | 开 / 关 |
| 打开登录页时自动填写并提交 | 开 / 关 |

> **为什么掉线间隔默认 1 秒？** 每次检查只是一个本地 `chkstatus` 请求（几百字节，
> 走内网不消耗流量），开销极小。加上自适应机制，已在线时不会频繁打扰门户。
> 而「压根连不上门户」的情况会走退避，不会一直每秒请求。

> **注销后会怎样？** 点「注销」需要二次确认。注销成功后插件会**暂停自动登录**
> （否则下一轮巡检会立刻把你重新登回去），面板会显示「已手动注销 · 自动登录暂停」。
> 想恢复上网在弹窗点「恢复登录」（或在设置页点「立即登录」）即可解除暂停。

> **提示「密码错误」怎么办？** 大概率是**运营商选错了**。到设置页把「运营商」换个选项再试。
> 本机实测使用 `校园用户`（无后缀）可以成功认证。

> **密码填错了会不会一直重试？** 不会。密码错 / 账号不存在 / 被锁定 / 已停机 / 已在别处登录
> 这类**凭据类错误**重试再多次也不会成功，插件会自动把重试间隔从 1 秒放宽到常规间隔
> （默认 10 秒），避免每天打出上万次无效认证。改好账号密码后点一次「立即登录」即可恢复快速重连。
> 注意：真·掉线（凭据正确、只是掉线了）仍保持 **1 秒**抢修，不受此影响。

## 工作原理

插件通过 JSONP 调用门户接口（与门户网页的 `a40.js` 完全一致）：

```
状态：GET /drcom/chkstatus?callback=dr1001&v=<随机>&lang=zh&jsVersion=4.1.3
登录：GET /drcom/login?callback=dr1002&DDDDD=账号&upass=密码&0MKKey=123456
      &R1=0&R2=&R3=<运营商代码 1~4>&R6=0&para=00&v6ip=&terminal_type=1&lang=zh-cn&jsVersion=4.1.3
```

返回形如：

```javascript
dr1002({"result":1,"uid":"13800000000","v4ip":"10.0.0.100",...});
```

- `result: 1` → 在线 / 登录成功
- `result: 0` → 失败，`msga` 字段说明原因（`userid error1` 账号不存在、`userid error2` 密码错误）

**插件先查状态再决定是否登录**，已在线时不会重复认证，避免把正常网络踢掉。

> **已处理的编码陷阱：门户声明的 `charset` 可能与实际字节不符。**
> 例如网关/代理把 UTF-8 内容标成 `charset=gbk`。GBK 几乎不会解码失败——任意字节都能
> "成功"解出字符——所以只信声明会静默产出 `鐧诲綍鎴愬姛` 这类乱码（`fatal` 也拦不住），
> 进而让 `msga` 中文提示失真、按中文关键字做的判定（宵禁/密码错误）失效。
> 插件改为先按**字节结构**判定：真实 GBK 中文几乎不可能是合法 UTF-8，而 UTF-8 字节
> 被当作 GBK 总能解出垃圾——因此「合法 UTF-8 且含非 ASCII 就按 UTF-8 解」即可同时
> 覆盖两个方向，其余情况再走声明优先 → `gbk` → `gb18030` → `utf-8` 回退。

## 常见问题

**Q：设置页还是旧界面（数字输入框、"建议 5 分钟"）？**
浏览器只在加载扩展时读代码，之后一直用内存里的旧副本。两种办法，任选其一：

**方法 A**：
1. 打开 `chrome://extensions/` 或 `edge://extensions/`（也可双击项目根目录的 `reload_extension.bat`）
2. 找到「Campus AutoLogin」卡片，点 **🔄 刷新** 按钮
3. **把已经打开的设置页标签关掉，重新打开**（旧标签页里跑的还是旧代码）

**方法 B**：**完全退出浏览器再重新打开**（关掉所有窗口）。重启后扩展会重新从磁盘加载。

4. 看设置页左上角品牌区的版本号：能正常显示当前版本，就说明刷新成功了

**Q：提示「不在校园网内 / 门户不可达」？**
当前没有连上校园网。连上 Wi-Fi 或网线后会自动恢复正常，这条不是错误。
此时插件会自动进入退避（最多 1 分钟一次），不会在你离开校园网后一直每秒发请求。

**Q：断网后多久能自动重连？**
正常情况**几乎无感**。插件监听浏览器的导航失败/跳转事件，网页打不开的瞬间就会重连；
掉线后还有每 1 秒的高频轮询兜底。最坏情况也就等约 1 秒。

**Q：点了「注销」怎么马上又连上了？**
旧版本存在这个问题，现已修复：注销成功后会暂停自动登录，
界面显示「已手动注销 · 自动登录暂停」，直到你在弹窗点「恢复登录」（或在设置页点「立即登录」）才恢复。

**Q：修改了账号密码不生效？**
设置页改完后要点「保存并连接」。如果还不行，按上面第一条刷新插件。

**Q：会不会一直重复登录把我的网踢掉？**
不会。每次都是先查 `chkstatus`，只有确认不在线才会发起认证。
另外无论任何时候，插件都不会把你从「已在线」状态踢下线。

**Q：密码安全吗？**
密码只存在本机浏览器的 `chrome.storage.local`（未加密，但不会同步到云端、不会上传到任何第三方服务器），
且插件只申请了访问 `172.30.100.2` 的权限（Chromium match pattern 未显式写端口时通配所有端口，
因此也覆盖注销接口使用的 `172.30.100.2:801`；内容脚本同样会注入到该 IP 的任意端口页面）。
注意：登录时密码会通过**明文 HTTP 查询参数**（`upass=...`）发送给校园网门户，这是门户协议本身决定的，
并非加密传输；请勿在不可信的公共网络环境使用。
源码与配置模板中**不含任何真实凭据**，首次安装后需要你自行到设置页填写。

## 卸载

打开 `chrome://extensions/`（Edge 用户打开 `edge://extensions/`）→ 找到「Campus AutoLogin」（或「校园网自动登录」）→ **移除**。
如需同时清除已保存的账号密码，移除插件即可（storage 会一并删除）。
