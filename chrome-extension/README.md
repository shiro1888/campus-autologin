# 校园网自动登录 · Chrome 插件

自动登录校园网门户 **http://172.30.100.2/**（Dr.COM / 哆点 ePortal），掉线自动重连。

> ### ⚠️ 改完代码没生效？先看这里
>
> Chrome 只在**加载扩展的那一刻**读取代码，之后一直用内存里的旧副本。
> 改了磁盘文件不点刷新是不会生效的 —— 这是 Chrome 的正常行为，不是插件的问题。
>
> **方法 A（推荐）**
> 1. 双击项目根目录的 **`reload_extension.bat`**（会自动打开 `chrome://extensions/`）
> 2. 在「Campus AutoLogin」卡片上点 **🔄 刷新**
> 3. **关掉已打开的设置页，重新打开**（旧标签页里仍是旧代码）
>
> **方法 B（最省事）**
> **完全退出 Chrome 再重新打开**。重启后所有扩展都会重新从磁盘加载。
>
> 确认成功的标志：设置页标题右边出现版本号 **v1.3.0**。

## 安装（30 秒）

1. 打开 Chrome，地址栏输入并回车：

   ```
   chrome://extensions/
   ```

2. 打开右上角的 **开发者模式** 开关

3. 点击左上角 **加载已解压的扩展程序**

4. 选择这个文件夹：

   ```
   C:\Project\campus-autologin\chrome-extension
   ```

5. 插件出现在列表里即安装成功。点击工具栏的插件图标 → **⚙ 设置**，确认账号密码后点 **保存并立即测试**。

> 如果工具栏看不到图标，点一下地址栏右侧的「拼图」图标，把「Campus AutoLogin」固定住。

## 功能

| 功能 | 说明 |
| --- | --- |
| **断网秒级重连** | 网页打不开 / 被跳到门户登录页的**瞬间**就重连，不等定时器 |
| **自适应加速** | 在线时低频检查；一旦掉线自动切到 **1 秒**高频重连，连上再切回 |
| **后台自动检查** | 在线默认 1 秒，可调 1 秒 ~ 30 分钟 |

| **登录页自动填写** | 被断网跳转到门户登录页时，自动填账号密码并点登录 |
| **手动登录** | 点插件图标 → 「立即登录」 |

## 重连有多快？

三层保障，从快到慢：

| 层级 | 触发时机 | 延迟 |
| --- | --- | --- |
| ① 断网跳转瞬间 | 导航失败 / 被跳到门户 | **≈ 0 秒** |
| ② 掉线后高频轮询 | 已确认掉线，每 1 秒重试 | **≤ 1 秒** |
| ③ 在线时低频轮询 | 常规守护，默认 1 秒 | 兜底 |

**关于 1 秒间隔**：Chrome 官方文档写 `chrome.alarms` 最快 30 秒，但那条限制
**只对「已打包 / 从商店安装」的扩展生效**；开发者模式加载的未打包扩展不受限制。
本插件在 Chrome 154 上实测：

```
闹钟 campus-auto-login  period = 0.0167 分 = 1.0 秒   ← Chrome 原样接受，未被夹紧到 30 秒
16 秒内触发 16 次                                     ← 精确 1 秒/次
```

> 如果你以后把这个插件打包发布到 Chrome 应用商店，间隔会被 Chrome 自动夹到 30 秒。
> 本地开发者模式加载使用不受影响。

## 设置项

| 选项 | 说明 |
| --- | --- |
| 账号 | 校园网账号（手机号 / 学号） |
| 密码 | 校园网密码，可点「显示」查看 |
| 运营商 | `校园用户` / `校园电信@dx` / `校园联通@lt` / `校园其他` |
| **在线时的检查间隔** | 默认 **1 秒**（可选 1 秒 / 5 秒 / 10 秒 / 30 秒 / 1~30 分钟） |
| **自适应加速** | **默认开** —— 掉线后自动切到「掉线间隔」，重连成功再切回 |
| **掉线后的检查间隔** | 默认 **1 秒**（可选 1 / 5 / 10 / 30 秒 / 1 分钟） |
| **断网跳转时立即登录** | **默认开**，最快的重连方式 |
| 浏览器启动时自动登录 | 开 / 关 |
| 打开登录页时自动填写并提交 | 开 / 关 |

> **为什么默认都是 1 秒？** 每次检查只是一个本地 `chkstatus` 请求（几百字节，
> 走内网不消耗流量），开销极小。加上自适应机制，已在线时不会频繁打扰门户。

> **提示「密码错误」怎么办？** 大概率是**运营商选错了**。到设置页把「运营商」换个选项再试。
> 本机实测使用 `校园用户`（无后缀）可以成功认证。

## 工作原理

插件通过 JSONP 调用门户接口（与门户网页的 `a40.js` 完全一致）：

```
状态：GET /drcom/chkstatus?callback=dr1001&lang=zh&jsVersion=4.1.3
登录：GET /drcom/login?callback=dr1002&DDDDD=账号&upass=密码&0MKKey=123456
      &R1=0&R2=&R3=<运营商>&R6=0&para=00&v6ip=&terminal_type=1&lang=zh-cn&jsVersion=4.1.3
```

返回形如：

```javascript
dr1002({"result":1,"uid":"REDACTED_CAMPUS_ACCOUNT","v4ip":"10.102.4.51",...});
```

- `result: 1` → 在线 / 登录成功
- `result: 0` → 失败，`msga` 字段说明原因（`userid error1` 账号不存在、`userid error2` 密码错误）

**插件先查状态再决定是否登录**，已在线时不会重复认证，避免把正常网络踢掉。

## 常见问题

**Q：设置页还是旧界面（数字输入框、"建议 5 分钟"）？**
Chrome 只在加载扩展时读代码，之后一直用内存里的旧副本。两种办法，任选其一：

**方法 A**：
1. 打开 `chrome://extensions/`（或双击项目根目录的 `刷新插件（重要）.bat`）
2. 找到「校园网自动登录」卡片，点 **🔄 刷新** 按钮
3. **把已经打开的设置页标签关掉，重新打开**（旧标签页里跑的还是旧代码）

**方法 B**：**完全退出 Chrome 再打开**（关掉所有窗口）。重启后扩展会重新从磁盘加载。

4. 看设置页标题右边的版本号：显示 **v1.3.0** 就说明刷新成功了

**Q：提示「不在校园网内 / 门户不可达」？**
当前没有连上校园网。连上 Wi-Fi 或网线后会自动恢复正常，这条不是错误。

**Q：断网后多久能自动重连？**
正常情况**几乎无感**。插件监听浏览器的导航失败/跳转事件，网页打不开的瞬间就会重连；
另外每 30 秒还有一次兜底检查。最坏情况也就等 30 秒。

**Q：修改了账号密码不生效？**
设置页改完后要点「保存并立即测试」。如果还不行，按上面第一条刷新插件。

**Q：会不会一直重复登录把我的网踢掉？**
不会。每次都是先查 `chkstatus`，只有确认不在线才会发起认证。

**Q：密码安全吗？**
密码只存在本机浏览器的 `chrome.storage.local`（未加密，但不会同步到云端、不会上传到任何服务器），
且插件只申请了访问 `172.30.100.2` 的权限。

## 卸载

`chrome://extensions/` → 找到「校园网自动登录」→ **移除**。
如需同时清除已保存的账号密码，移除插件即可（storage 会一并删除）。
